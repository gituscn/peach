# ADR-0130：WebDAV 媒体只读访问

- 状态：已接受；真实服务兼容性待验证
- 日期：2026-10-30
- 关系：补充 ADR-0021、ADR-0115、ADR-0123

## 决策

使用 Python 标准库 `urllib` 访问明确声明的 WebDAV 媒体根：`PROPFIND` 读取目录与元数据，带 `Range` 的 `GET` 读取字节区间。存储根目录记录 `transport = 'webdav'` 与不含凭据的 `mount`；媒体库、根目录身份和账本前缀保持稳定。凭据按根目录身份单独保存到本机 CredentialStore，键为 `webdav-<root_id>`。

`WebDavResource` 继承既有 `SmbResource` 的远端路径身份，扫描、`media_io`、播放响应和回环桥继续消费同一套路径解析与读取入口。传输只实现 `stat`、`scandir`、`open` 与读取；改名、删除、目录创建和写入在资源与传输两层都拒绝，服务器返回的权限不改变只读边界。

请求禁用环境代理，使用固定超时和 Basic 认证；目录响应按本地名解析 XML 命名空间，地址按百分号解码后的分量规范化。读取句柄按 4 MiB 预取范围，顺序读取复用同一响应，seek 丢弃旧响应后重新请求。FFmpeg 和 ffprobe 继续通过仅监听回环地址、携带进程内随机访问凭据的 HTTP Range 入口读取。

## 取舍

不引入 `httpx` 之外的 WebDAV 客户端或 `fsspec` 封装：协议子集只覆盖读取，标准库足以实现固定的请求期限与取消语义。WebDAV 的 `Range` 支持由服务器决定；忽略范围的服务器不降级为整文件下载，而是报告读取错误。写操作不提供“尽力而为”的远端事务，避免只读来源与账本恢复语义冲突。

隔离回归覆盖地址与凭据、只读方法拒绝、嵌套目录、范围读取、扫描和回环桥。真实服务的认证策略、吞吐和断网恢复尚待目标环境验证。
