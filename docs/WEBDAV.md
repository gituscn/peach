# WebDAV 媒体来源

Peach 通过 HTTP 或 HTTPS 上的 WebDAV 只读访问媒体目录。连接由运行 Peach 的机器建立；浏览器和外部播放器使用 Peach 的媒体地址，不接收 WebDAV 账号和密码。

## 添加目录

在「设置 → 媒体库与入库」添加文件夹，来源选择「WebDAV」，路径填写 `http://nas.example/dav/Movies` 或 `https://nas.example/dav/Movies`。地址不含账号、密码、查询参数或片段，目录必须指向要扫描的根。

填写账号和密码后点击「测试连接」。成功时可选择进入子目录，再测试该目录。保存配置后由应用管理入口重新加载；首次使用的目录可选择扫描并补全资料。

密码不回显，留空保留已保存的密码；更换账号时填写对应密码。「移除已保存的 WebDAV 账号」在保存时删除本机凭据。凭据位于数据目录的 `secrets/follow/webdav-<root_id>.json`，不进入账本或配置响应。该文件不是加密保险箱，应限制数据目录的访问权限。

## 范围与限制

WebDAV 来源固定为只读。扫描、NFO、配套图片和字幕通过 `PROPFIND` 与字节范围 `GET` 读取；资料、预览和转码结果保存在 Peach 数据目录。Peach 不写入、改名或删除远端文件，服务器授予的写权限也不改变这一点；整理与永久删除不会作用于 WebDAV 来源。

媒体工具通过回环 HTTP Range 地址随机读取；这个供工具读取的地址只提供 GET/HEAD，不能借它写回远端。原件修复仍要求本机挂载路径，不将整部远程影片自动下载到临时目录。

远端离线、认证失败或目录不可读时保留馆藏记录，不能据此断言文件已删除。直接 WebDAV 来源使用扫描，不加入本机文件监视。服务器必须支持 `PROPFIND`（Depth 0/1）和 `GET` 的 `Range`；忽略字节范围的服务器会使播放与媒体工具报告读取错误。每个读取句柄拥有独立连接与文件位置，请求超时关闭所属连接，恢复网络后重新发起操作。

## 配置文件

使用配置文件管理的部署，在 `[media.storage_roots.<root_id>]` 中填写 `transport = 'webdav'`、`mount = 'https://nas.example/dav/Movies'`，保留稳定的 Windows 格式 `root` 及 `library_id`。账号文件使用 `{"username":"reader","password":"<密码>"}` 的结构，限制访问权限，不进入公开仓库。已有馆藏更换地址时，保留目录身份并明确选择重定位。

## 验证范围

隔离回归覆盖地址规范化、凭据保留与回滚、只读方法拒绝、嵌套目录、字节范围读取、配置与扫描字幕配对、回环桥及测试连接入口。真实 WebDAV 服务的认证策略、吞吐、长时间播放及断网恢复需在目标环境验证。
