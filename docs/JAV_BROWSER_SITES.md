# JAV 用户脚本站点清单

清单登记 55 项站点，包含各项下明确列出的域名及其子域。12 项配置作品详情页自动识别规则，43 项使用选中番号添加。域名登记不表示站点当前可达，也不表示已完成真实浏览器扩展与网盘下载的联合验收。

「自动识别」读取详情页的主标题与明确番号字段，识别不到或存在冲突时使用脚本菜单。「选中番号」需要用户选中一个完整番号，选择脚本菜单「选中番号加入 Peach」，再点击添加按钮。两种方式都由 Peach 最终校验番号并执行同一条磁力搜索、云下载和入库流程。安装方法见[用户脚本](JAV_BROWSER.md)。

站点配置唯一来源为 [`jav-sites.json`](../web/integrations/jav-sites.json)。安装端点据此生成脚本的 `@match` 与运行规则，服务端据此核对来源域名和允许保留的作品参数，设置页显示同一份清单。

- [NJAV](https://njav.tv/en) 的迁址公告及 123AV 详情链接已取得，`123av.com` 按主站证据登记。
- [JAV.guru](https://jav.guru/)、[JAVtiful](https://javtiful.com/)、[7mmtv](https://7mmtv.sx/)、[AVBase](https://www.avbase.net/) 和 [JAVDatabase](https://www.javdatabase.com/) 的主页或详情链接结构已取得；7mmtv 详情正文未取得。
- JavDB 与 JavLibrary 本次只读网页请求返回 403，Jav321 请求超时，JavBus 未取得。自动规则同时参照项目既有解析器与离线页面夹具，真实扩展验收仍未取得。

- R18.com、Avgle 等历史入口，及 AIRAV、FC2Club、FreeJAVBT、AVSOW 等补充来源的当前域名和页面结构待核验，不默认注入。

浏览器测试使用合成页面与模拟 GM API，真实站点、扩展和网盘的联合验收未取得。未取得页面证据的站点使用选中番号方式，不声称已完成自动解析。
