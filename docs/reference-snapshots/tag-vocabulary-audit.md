# 标签词表审查

核验日期：2026-10-10。来源：本机 ledger 只读查询、`genre_taxonomy`、`catalog_rules` 与共享显示模块 `frontend/src/core/tags.ts`。

## 审查结果

- 账本共有 1,655 个标签名称，其中 1,409 个为 `演员:` 兼容标记，246 个为实际标签；标签实体也为 246 个。
- 截图中的 `OL` 是 `OL制服` 的界面显示名。`OL制服` 表达着装，`秘书OL` 表达角色，两者保留独立筛选。制服使用完整名称，并归入外观分组；`JK制服` 采用相同口径。
- 来源词 `OL`、`Office Lady`、`Secretary` 共用 `秘书OL`；手动添加退役名称通过 `current_tags` 归一，详情缓存、最近使用和撤销采用 API 返回的规范名。
- `猫耳` 与 `貓耳女` 共用具体标签 `猫耳`。`兽耳兽装` 是独立的宽泛着装标签。
- 来源映射的规范化键未发现冲突。现有退役标签名在实际标注中的存量为零。
- 10 个本地 NFO 原词仍在实际标注中，共 22 条。其中 3 条与目标标签在同一资产上并存；全部归属为 `javinizer:local_nfo:tag`。
- 「其他内容」分组共有 34 个名称，含上述 10 个来源词。其余 24 个包括平台出处、自定义标记和未收录的描述，如 `Iカップ`、`グリグリ`、`テカテカ`、`個撮`、`未公開`、`無編集`、`神乳`、`長編`；没有足够依据时保留原词，不据字面猜测合并。

## 影响面

- 数据层：新增标签继续写扁平标注与标签实体；复用退役词表归一，不改 schema，不批量改真实 ledger。
- API：`/api/item/tag` 的 `tag` 返回规范名；隐藏采用请求中的具体名称，保留来源证据。
- 页面：共享标签显示覆盖首页、详情、沉浸、实体页、标签页和统计；手动添加、最近使用及撤销共用规范名。其余页面没有独立映射。
- 反向状态：添加后的撤销使用服务端返回的标签身份；规范标签已经存在时，添加同义词不提供撤销原标签的操作。
- 文档：本审查记录来源、判断及未执行的存量处理。安装与配置方式没有变化，无新增 ADR 或智能体规则。
